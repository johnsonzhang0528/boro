## Pending, Processing, Rejected: কোন স্ট্যাটাসে কী করবেন

Withdrawal cancel করার আগে status language বুঝতে হবে। এখানেই বেশিরভাগ user ভুল করেন।

### Pending

এটাই সেই stage যেখানে cancel করার সম্ভাবনা সবচেয়ে বেশি। অর্থাৎ request submit হয়েছে, কিন্তু backend payout queue এখনো final processing শুরু করেনি। আপনি যদি amount বদলাতে চান, wrong number ঠিক করতে চান, বা KYC mismatch বুঝে থাকেন, এই সময়েই action নিন।

### Processing

এই stage মানে request internal review বা payment dispatch-এ ঢুকে গেছে। এখানে self-service cancel button অনেক সময় আর দেখায় না। তখন request force cancel করার চেষ্টা না করে support ticket খুলুন।

### Rejected

Rejected হলে আসলে cancel করার প্রশ্ন থাকে না, কারণ request already reverse হয়ে যাওয়ার কথা। তখন focus হবে rejection reason fix করা। এ জন্য [Withdrawal Rejected? Understanding Error Codes](/blog/withdrawal-rejected-reasons/) পড়া বেশি useful।

## কখন cancel করা উচিত

সব pending withdrawal cancel করা smart decision নয়। নিচের পরিস্থিতিতে cancel করা যুক্তিযুক্ত হতে পারে:

- amount ভুল দিয়েছেন
- ভুল bKash, Nagad, বা Rocket number দিয়েছেন
- account name mismatch বুঝেছেন
- withdrawal-এর আগে bonus wagering বা turnover complete হয়নি বুঝেছেন
- অন্য payment method ব্যবহার করলে payout দ্রুত হবে বলে সিদ্ধান্ত নিয়েছেন

কিন্তু যদি request already ১০ থেকে ২০ মিনিটের মধ্যে normal queue-তে থাকে, অকারণে বারবার cancel-submit করলে delay আরও বাড়তে পারে। বিশেষ করে network busy থাকলে সেটা counterproductive হয়।

## Cancel button না থাকলে কী করবেন

এখানে অনেকে ভুল করে নতুন করে আরেকটি withdrawal request submit করেন। সেটা করবেন না। তার বদলে:

1. request amount লিখে রাখুন
2. request time note করুন
3. payment method note করুন
4. transaction/request ID থাকলে কপি করুন
5. live chat support-এ একবার clear message পাঠান

একটি workable message হতে পারে:

> My withdrawal request is still pending, but I need to cancel it before processing. Please reverse it to my wallet balance if it has not been dispatched yet.

## Balance ফেরত না এলে কতক্ষণ অপেক্ষা করবেন

Pending withdrawal cancel করার পর balance অনেক সময় সঙ্গে সঙ্গে ফিরে আসে। তবে কিছু ক্ষেত্রে system sync delay থাকতে পারে। practical guideline:

- ৫ মিনিট: initial wallet refresh
- ১০ থেকে ১৫ মিনিট: cache বা sync delay clear হওয়ার সময়
- ৩০ মিনিট+: support follow-up করার সময়

যদি এই সময়ের পরেও balance না ফেরে, screenshot সহ support-এ যোগাযোগ করুন। আর যদি বারবার pending status-এ সমস্যা হয়, [Ultimate Guide to Online Casino Payments in Bangladesh](/blog/ultimate-guide-to-online-casino-payments-bangladesh/) থেকে method-specific rules compare করা ভালো।

## Common mistakes (সাধারণ ভুল)

### একই সময়ে multiple withdrawal request দেওয়া

একটি request cancel না হওয়া পর্যন্ত নতুন request পাঠালে review queue জটিল হতে পারে।

### Processing status-এ গিয়েও self-cancel আশা করা

এই stage-এ অনেক platform user-side cancel আর allow করে না।

### Support-এ incomplete তথ্য পাঠানো

শুধু “withdrawal cancel করুন” লিখলে resolution slow হয়। amount, time, method, এবং status লিখুন।
